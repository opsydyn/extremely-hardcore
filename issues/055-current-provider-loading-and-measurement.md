standardized command-wall-time observation without claiming adherence,
productivity, provider comparison, or release readiness.

- Capture current versions and Codex discovery state.
- Run read-only Codex and Claude loading smokes with private output handling.
- Repeat a fixed EHS status/summary path three times and report durations.
- Align provider onboarding, dogfood status, and roadmap wording.

## completion criteria

- Measurement records three repetitions, exit states, and summary durations,
  and explicitly says active operator time was not measured.
- Public docs preserve loading/adherence/comparison/release boundaries.
- Run 055 has complete evidence, high-risk approval, zero blockers, and valid
  local projections.

## non-goals

- No writable execution, provider comparison, benchmark, skills-effect study,
  containment probe, network-isolation claim, runtime change, adapter, or
  dependency.
- No credential, raw transcript, or session-state retention.
